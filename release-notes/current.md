<summary>Windows 版启动器迁移到 Avalonia 界面。</summary>

## 更新内容

- Windows 版界面使用 Avalonia，沿用现有的游戏目录和启动器数据。
- 双击启动器后会尽早显示小窗，小方块在三级跳台间跃动，主界面绘制好后柔和淡入。
- 运行此版本需要与启动器架构（x64 或 ARM64）一致的 [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0)。
- 雾玫瑰主题调为低饱和度。统一按钮、卡片和浮层的超椭圆圆角，加大窗口外框圆角，并让投影更柔和。
- 启动器按界面高度统一投影范围，修复 Minecraft 版本卡片的投影被裁断的问题。
- 修复按钮等控件的细边框在超椭圆转角处局部变淡、粗细不匀的问题。
- 修复深色桌面上窗口圆角边缘出现浅色细线的问题。
- 修复 PCL 写入游戏窗口设置后，Minecraft 可能无法读取已有设置的问题。
- 修复本地构建遗漏微软登录配置，导致正版档案启动游戏失败的问题。
- 配置自建大厅服务后显示大厅及联机设置。下载 EasyTier 遇到损坏或不完整的压缩包时会自动切换下载源，同一次失败只提示一次。
- 修复启动和设置页的更新日志弹窗显示摘要标签的问题。

<summary>修复 Windows 自更新中断的问题，并在未配置遥测地址时自动关闭遥测。</summary>

## 更新内容

- Windows 更新时，如果原 EXE 仍被短暂占用，启动器会自动重试替换，并按原文件名重启。从本版发起更新时，旧窗口会等更新程序就绪后再关闭；若准备失败，会保留窗口并显示原因。
- 未配置遥测地址时，启动器会隐藏遥测弹窗和设置开关，跳过采集。此前点过「同意」的用户，下次启动时会自动关闭这项设置。

从 2.15.8 等旧版升级时，需要安装与启动器架构（x64 或 ARM64）一致的 [.NET 11 Runtime](https://dotnet.microsoft.com/download/dotnet/11.0)。

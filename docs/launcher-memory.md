# Windows 启动器内存与动效优化

## 测量基线

2026-11-25，在 Windows x64、RTX 4070 SUPER、约 60 Hz 环境下，用 2.15.10 和 2.15.11 发布标签构建 Release 测量版。空白首页启动 25 秒时，WPF 版工作集为 192–202 MiB，私有内存为 101–111 MiB。Avalonia 版分别为 222–229 MiB、197–198 MiB。两版 GC 堆提交量均约 20 MiB。

在首页和默认设置页之间往返 6 轮，2.15.11 首次进入设置的首个 UI 帧回调耗时 93–94 ms，后 5 轮平均帧间隔为 17.0–17.8 ms。全部宿主按需创建可省约 10 MiB 私有内存，首次切设置增至 145 ms。软件渲染将私有内存降至 70 MiB，重复转场平均帧间隔增至 24.8 ms。本地原始记录位于 `artifacts/research/2.15.11-memory-frames.json`。

## 实现范围

1. 修复长列表的离屏回收。在视口附近保留卡片，快速来回滚动时复用已创建的内容。屏幕外长期不用的控件和图片可回收。兼顾截图网格、资源列表的选择与操作、资讯卡片，以及其他已启用回收的调用方。
2. 下载资源图标按显示尺寸与 DPI 解码。按字节限制已解码缩略图缓存，使短距离回滚或重复浏览可以命中缓存。异步加载须核对当前请求，处理卸载、重绑、文件替换和并发使用时的位图所有权。
3. 首页、设置等常用宿主保留原有预热和实例复用。日志、任务、资源详情等低频宿主在首次访问时创建，后续访问复用同一实例。
4. Windows 默认继续使用 GPU 加速，已有“禁用硬件加速”设置在下次启动时选择软件渲染。

## 验收

- 用 200 个等高条目和可容纳 5 行的视口滚到底再回顶。原实现最终挂载 200 行、回收回调为 0。记录修改后的驻留峰值、回收次数以及近距离回滚时的重建次数，同时检查布局、点击、选择与异步图片绑定。
- 验证图标在不同缩放比例下的解码尺寸、共享缓存所有权与容量淘汰。已经显示的图片在其他控件释放或缓存淘汰时仍应可用。
- 使用默认硬件渲染对比首次进入设置和重复转场的帧间隔，并确认再次访问复用原页。分别检查低频宿主首次创建、注册查询与软件渲染设置。
- 交付时记录同机实测结果、测试场景和本次可确认的收益。空白首页与长列表分别统计。

## 实现与实测

### 长列表与图片

启用回收的列表在条目可见时创建内容。离开视口后，上下各保留一个视口内已经创建的内容，更远的条目只保留布局占位和最近的实测尺寸。截图页另留最多 8 张可重新绑定的空卡片，同一张截图回到视口时沿用已展示状态。资源图标按 50 DIP 的显示槽和当前屏幕缩放解码。最近释放的缩略图按解码像素字节估算，共享缓存上限为 16 MiB，正在显示的位图由使用它的控件继续持有。

在同一台机器上对比原始 2.15.12（`49584f67`）与修改后的 x64 Release。通过实例设置页打开 200 张不同的 800×450 PNG，视口高 468 DIP，每 70 ms 移动 150 DIP，滚到底再逐步回到顶部。在底部等待 1.2 秒、顶部等待 1.4 秒，读取进程内存，全程使用默认 GPU 渲染和自然 GC。

| 同一趟截图浏览 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 实际使用过的卡片实例数 | 200 | 21 |
| 滚到底时挂载的卡片 / 已解码图片 | 200 / 200 | 17 / 17 |
| 回到顶部时挂载的卡片 / 已解码图片 | 200 / 200 | 15 / 15 |
| 滚到底时的私有内存 / 工作集 | 385.5 / 425.2 MiB | 313.6 / 343.1 MiB |
| 回到顶部时的私有内存 / 工作集 | 380.0 / 418.7 MiB | 290.9 / 333.4 MiB |
| 回滚时 UI 帧回调平均间隔 / P95 | 20.4 / 33.5 ms | 18.6 / 33.4 ms |

回到顶部后，逐一核对了 15 张挂载图片的路径和实际像素，均对应各自的截图。另用可容纳 5 行的等高列表滚过 200 行，真实控件峰值为 10 个，短距离滚回 2 行时新增控件为 0。40 张 256×256 的下载图标在 125% 缩放下解码为 63×63，像素缓冲从 10.00 MiB 降到 0.61 MiB。

### 启动与切页

启动时创建的页面宿主从 11 个降为 4 个，分别是启动、下载、设置和工具。实例选择、实例设置、存档管理、资源详情、帮助详情、任务管理和游戏日志在首次访问时创建并保留。仅查询页面是否注册不会触发构造。Windows 默认走 GPU，明确启用“禁用硬件加速”后重启，测量进程切换到软件渲染。

每次启动后先在空白首页停留 25 秒，再在首页和默认设置页之间往返 6 轮。首帧从发起导航计时，后 5 轮合计 10 次重复转场，每次采集 850 ms 的 UI 帧回调，并用对象引用核对页面复用。

| 独立进程实测范围 | 优化前，4 次启动 | 优化后，3 次启动 |
| --- | ---: | ---: |
| 空白首页私有内存 | 196.8–199.4 MiB | 194.3–197.2 MiB |
| 空白首页工作集 | 227.4–230.0 MiB | 224.3–233.4 MiB |
| 首次进设置，首个 UI 帧回调 | 93.7–120.1 ms | 115.1–116.6 ms |
| 重复切页，首个 UI 帧回调的单次运行中位数 | 0.52–0.62 ms | 0.48–0.69 ms |
| 重复转场，平均帧间隔 | 17.1–17.3 ms | 17.1–18.4 ms |
| 重复转场，P95 帧间隔 | 30.5–31.2 ms | 30.8–33.3 ms |

优化后的 30 次重复转场全部复用了原页面。首次进入设置仍需约 116 ms，重复切页中最慢的首个回调为 4.0 ms。三次启动中有一次转场平均间隔为 18.4 ms，另外两次约为 17.2 ms。空白首页私有内存只下降了数 MiB，主要收益出现在浏览长列表之后。

### 回归验证

.NET 11、Release/x64 的 51 项相关自动化测试全部通过，覆盖导航、视口回收、缩略图、配置、资讯和资源搜索。缩略图测试覆盖两个控件共享位图、动态 DPI、原图重挂与同名文件替换。独立验证还覆盖 100%、125%、150%、200% 四档缩放，缓存淘汰时的活动位图，异步重绑，硬件加速旧配置迁移，以及测试启动日志的首行输出。
